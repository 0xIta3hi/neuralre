Review the following categories where applicable:

1. Memory-safety issues
   - Stack, heap, or global buffer overflows
   - Out-of-bounds reads or writes
   - Missing bounds checks
   - Use-after-free, double-free, or invalid pointer use
   - Null-pointer dereferences
   - Integer overflow or truncation affecting allocation or indexing

2. Unsafe input and string handling
   - Use of gets, strcpy, strcat, sprintf, scanf-family functions, or unsafe format strings
   - User-controlled data reaching memory-writing operations
   - Missing length validation or incorrect size calculations
   - Format-string vulnerabilities

3. Dangerous operations
   - Calls to system, exec, popen, or shell interpreters
   - File, registry, or configuration writes using untrusted data
   - Dynamic library loading or function-pointer calls
   - Memory made writable and executable
   - Weak or incorrect cryptographic usage when visible from the evidence

4. Logic and authorization weaknesses
   - Missing authentication or authorization checks
   - Trust decisions based on attacker-controlled values
   - Insecure comparisons or predictable security-sensitive values
   - Error handling that exposes sensitive information or leaves unsafe state

- Whether the finding is confirmed, likely, possible, or unsupported

Limitations:
